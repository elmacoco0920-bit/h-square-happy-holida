# H平方｜Happy Holiday

韓系童裝品牌展示網站。

## 直接在 GitHub 修改

- 首頁文字與按鈕：`index.html`
- 選衣間與九套商品資料：`shop.html`、`app.js`
- 品牌故事：`story.html`
- 顏色、字體、手機／平板／電腦排版：`style.css`

在 GitHub 打開檔案後，按右上角的鉛筆圖示即可編輯。完成後按 **Commit changes**；網站會在約一分鐘內自動更新。

## 更換商品照片

目前商品照片保留空白。之後上傳照片到 GitHub 後，可以把照片檔案放進 `images` 資料夾，並在 `app.js` 的商品資料中替換圖片路徑。
